{% include "_icone.html" with nome="assistente" %}Claude Desktop

Aqui você liga o Claude Desktop ao sistema. Depois disso, em uma conversa do Claude você pede coisas como “Roberto pagou 157,50 no Pix hoje” ou “quem está atrasado?”, e ele consulta e registra no sistema. Antes de gravar, o Claude sempre pergunta se pode, e você clica em Permitir.

{% include "_icone.html" with nome="alerta" %}

Muito importante: sempre “Permitir uma vez”

Quando o Claude for registrar algo (um pagamento, um bloqueio…), o Claude Desktop abre uma pergunta com botões. Clique em Permitir uma vez, todas as vezes.

Não funcionou? Instalação manual (para quem entende de computador)
  1. Baixe o conector (celulares_mcp.py) e guarde numa pasta sua.
  2. No Prompt de Comando: pip install "mcp<2" (Python 3.10 ou mais novo).
  3. No Claude Desktop: Configurações → Desenvolvedor → Editar configuração. Adicione em mcpServers um item chamado celulares com command igual ao caminho completo do python.exe (descubra com where python), args com o caminho do arquivo e env com CELULARES_URL = {{ url }} e CELULARES_CHAVE = a sua chave.
