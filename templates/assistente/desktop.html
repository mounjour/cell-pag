Passo a passo

  1. Crie a sua chave (formulário abaixo) e copie o trecho de configuração que aparece.
  2. Baixe o conector (arquivo celulares_mcp.py) e guarde na sua pasta de usuário, por exemplo C:\Users\SEU_USUARIO\celulares_mcp.py.
  3. Instale a peça que ele usa: abra o Prompt de Comando e rode pip install "mcp<2" (precisa do Python 3.10 ou mais novo; as aspas e o <2 são importantes).
  4. No Claude Desktop: Configurações → Desenvolvedor → Editar configuração. Cole o trecho do passo 1 (ajustando o caminho do arquivo) e salve. Feche e abra o Claude Desktop de novo. As ferramentas do sistema aparecem no ícone de ferramentas da conversa. Se não aparecerem, troque "python" no trecho pelo caminho completo do Python (rode where python no Prompt de Comando para descobrir).
  5. Crie um Projeto no Claude Desktop e cole as instruções do quadro mais abaixo nas “instruções do projeto”. Converse dentro desse Projeto.
  6. Na primeira vez que o Claude usar uma ferramenta de gravar, o Desktop pergunta se permite. Escolha Permitir uma vez. Não escolha “Sempre permitir” nas ferramentas de gravar: é essa pergunta que garante que nada é registrado sem você ver.
