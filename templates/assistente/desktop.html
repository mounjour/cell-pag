Como usar no dia a dia: escolher a conversa

O sistema funciona em qualquer conversa do Claude Desktop onde o conector “celulares” estiver ligado. Mas é dentro do Projeto que o Claude segue as instruções da empresa. Por isso, sempre assim:

  1. Abra o Claude Desktop e clique em Projetos (menu do lado esquerdo).
  2. Clique no projeto que você criou no passo 4 (por exemplo, “Financeiro LA Iphones”).
  3. Clique em Nova conversa dentro do projeto. Cada conversa ali já nasce com as instruções. Para continuar uma conversa antiga, abra-a pela lista de conversas do próprio projeto.
  4. Perto da caixa de mensagem, confira que celulares está ligado no ícone de ferramentas.
  5. Escreva o pedido, por exemplo “quem está atrasado hoje?”. Quando o Claude for registrar algo, clique em Permitir uma vez.

Os nomes dos menus podem variar um pouco conforme a versão do Claude Desktop. Conversas abertas fora do Projeto não seguem as instruções, então evite usá-las para o financeiro.

Não funcionou? Instalação manual (para quem entende de computador)
  1. Baixe o conector (celulares_mcp.py) e guarde numa pasta sua.
  2. No Prompt de Comando: pip install "mcp<2" (Python 3.10 ou mais novo).
  3. No Claude Desktop: Configurações → Desenvolvedor → Editar configuração. Adicione em mcpServers um item chamado celulares com command igual ao caminho completo do python.exe (descubra com where python), args com o caminho do arquivo e env com CELULARES_URL = {{ url }} e CELULARES_CHAVE = a sua chave.
